# Expert Panel Consultant — لجنة خبراء استشارية

مهارة (Skill) لـ Claude تجعله يعمل كفريق استشاري، لا كمساعد يجيب بصوت واحد. تناسب أسئلة الاستراتيجية، ودخول الأسواق، والمنتج، والتسعير، وتقييم الاستثمارات.

## الفكرة

التقرير الاستشاري لا يساوي أكثر من أضعف رقم فيه. لذلك تقدّم المهارة الدقة على البلاغة: كل رقم له مصدر ورابط وتاريخ، وكل استنتاج موسوم بأنه **موثّق** أو **معيار قطاع** أو **فرضية** تحتاج اختبارًا.

يمر كل طلب بسبع مراحل:

1. **التوجيه**: تحديد اللغة ونوع الطلب والخبراء المناسبين.
2. **تثبيت السياق**: المنتج، الشريحة، السوق، القرار، نقطة البداية، وعمق التحليل.
3. **تأطير القرار**: تحويل السؤال الحرفي إلى قرار واضح، مع خيارات تشمل دائمًا «إبقاء الوضع» و«جمع معلومات أولًا».
4. **البحث**: باحثون يجمعون الأدلة بالتوازي، مع روابط وتصنيف لقوة كل مصدر.
5. **نقاش اللجنة**: خبيران أو ثلاثة (الوظيفة × الصناعة) يبني كلٌّ منهم على الآخر أو يعترض عليه، ومحلل كمي يبني السيناريوهات والرسوم البيانية بالكود.
6. **التوصية الموحّدة**: الجواب أولًا، ثم المتغيرات التي تقلب القرار، والخطوات التالية، والمؤشرات، والمخاطر، وشروط صلاحية التوصية.
7. **المراجعة المستقلة**: مراجع لم يكتب المسودة يفحصها بقائمة تدقيق قبل التسليم.

### مستويات العمق

| المستوى | ما يحصل عليه القارئ |
|---|---|
| D1 قراءة تشخيصية | ما هو صحيح الآن وكيف تتشكل الفرصة، بلا حكم |
| D2 قرار | حكم واضح مع شروطه ومحفّزاته (الافتراضي) |
| D3 خطة | القرار مع الاستراتيجية وخطة بمبادرات ومسؤولين وميزانيات ومؤشرات |
| D4 خارطة طريق | الخطة مع المراحل والاعتماديات والبوابات والتوقيت |
| D5 مخرج تنفيذي | المحتوى في مستند أو عرض جاهز لجمهور محدد |

ويختار المستخدم مدى تدخّله: توقف واحد لاعتماد الإطار (الافتراضي)، أو توقف بعد كل مرحلة، أو تشغيل كامل دون توقف.

## التثبيت

### في Claude Code

للاستخدام في كل مشاريعك:

```bash
git clone https://github.com/listentosaad/expert-panel-consultant.git ~/.claude/skills/expert-panel-consultant
```

أو لمشروع واحد فقط، من داخل مجلد المشروع:

```bash
git clone https://github.com/listentosaad/expert-panel-consultant.git .claude/skills/expert-panel-consultant
```

ابدأ جلسة جديدة، وستظهر المهارة في قائمة المهارات المتاحة.

### في تطبيق Claude (claude.ai)

1. اضغط المجلد في ملف ZIP بحيث يكون مجلد `expert-panel-consultant` (وفيه `SKILL.md`) في جذر الملف.
2. افتح إعدادات Claude، ثم قسم المهارات (Skills)، وارفع الملف.
3. فعّل المهارة.

## الاستخدام

اطرح سؤالك الاستراتيجي مباشرة، وسيستدعي Claude المهارة تلقائيًا، أو اطلبها بالاسم. أمثلة:

- «هل يستحق السوق السعودي إطلاق بديل عربي لأداة إدارة مهام؟»
- «نفكر في رفع السعر 20٪، ما أثره على الاحتفاظ بالعملاء؟»
- «مطعمنا يعتمد على تطبيقات التوصيل، هل نبني تطبيقًا خاصًا؟»

تُكتب المخرجات بلغة السؤال، وبالعربية الفصحى الرصينة عند السؤال بالعربية.
